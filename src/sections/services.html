Bidang Kompetensi & Solusi

Keahlian teknis yang siap saya kontribusikan:

Berfokus pada stabilitas jaringan, performa infrastruktur server Linux, kualitas software, serta keandalan hardware.

1.Network Engineering & Routing

Perancangan topologi, segmentasi subnetting (VLSM), implementasi VLAN, routing dinamis OSPF, administrasi Mikrotik RouterOS, dan simulasi Cisco Packet Tracer.

2.Linux System & Web Server Administration

Instalasi, hardening, dan konfigurasi server Linux (Ubuntu/Debian), manajemen Web Server (Nginx, Apache), virtualisasi sistem, dan pemantauan performa server.

3.Containerization & Cloud Foundation

Standarisasi lingkungan kerja dengan Docker containerization, integrasi version control Git/GitHub, alur CI/CD dasar, serta eksplorasi cloud computing AWS.

4.Software Engineering & QA Testing

Pengembangan web modern berbasis React.js, Next.js, Laravel, dan Golang, pembuatan plugin, serta pengujian fungsional dan API terstruktur menggunakan Postman.

5.Hardware Maintenance & Troubleshooting

Pemeriksaan dan perbaikan hardware/software komputer dan laptop, perakitan PC, upgrade komponen (RAM, SSD), instalasi OS, serta perawatan berkala.
